# 燕霞诊所管理系统 · 使用说明（v0.1.0）

## 1. 启动

1. 解压 `YanxiaClinicManagementSystem-0.1.0-win-x64.zip` 到普通目录（如 `C:\Users\HP\Desktop` 或 `C:\Apps`）。
2. 双击 `yanxia-clinic.exe`。
3. 不需要安装、不需要登录、不需要联网。

如果双击后没有窗口（常见于沙箱/AI 工具创建的低完整性桌面目录），请双击 `启动燕霞诊所管理系统.cmd`。它会把程序复制到 `%LOCALAPPDATA%\Programs\YanxiaClinicManagementSystem` 后启动，数据也保存在那里。更多见 [启动问题排查](TROUBLESHOOTING.md)。

普通目录下，软件目录的 `data/` 是数据文件夹，**不要手动改里面的文件**。搬走整个软件文件夹，数据就一起搬走；使用启动脚本时，数据在 `%LOCALAPPDATA%\Programs\YanxiaClinicManagementSystem\data`。

## 2. 药房

- 先到药房“添加药品”：名称、入库日期、库存、单位、预警库存、成本、标价等。
- 库存 ≤ 预警值时，处方首页/药房会提示，并在铃铛里生成通知。
- 点药品进详情，可以“进货”：填日期、数量、单位成本，库存自动增加，成本价更新。
- 已被处方使用过的药品不能删除，只能“停用”；停用后不会出现在开方搜索里，历史处方不受影响。

## 3. 处方

- 处方首页可以卡片/列表查看、搜索、按时间筛选。
- 点“添加处方”，填患者信息、诊断、Rp、医师；从药房添加用药，填数量、服用方式、服用频率。
- 金额自动计算：数量 × 标价；成本自动计算：数量 × 成本价。
- 点击处方卡片正文或列表行进入处方详情页；详情页显示全部信息，并提供编辑、打印、删除。
- 保存时自动扣库存；编辑数量按差额调整；删除处方会退回库存。
- 库存不足会提示，确认后允许暂时为负，补进货后回正。
- 可以打印预览、导出单张 PDF，或勾选多张批量导出。

## 4. 财务

- 日/周/月/年账本，按处方开具日期统计。
- 收入 = 药品金额 + 注射费；成本 = 各用药数量 × 成本价；盈利 = 收入 − 成本。
- 周账本按周一到周日；点明细行可以看期间处方。

## 5. 通知

- 右上角铃铛：有未读时显示红点和数量。
- 点通知跳到药品详情；补货后未读通知自动标为已读。
- 通知只在软件内显示，不做系统托盘或手机推送。

## 6. 主题

右上角“外观”可以切换：

- 白天模式：默认。
- 夜间模式：深色界面。
- 阅读模式：暖纸色、正文稍大、行高更松。

## 7. 打印 / PDF

点“打印”会生成 **正 32 开（130×190mm）图片模板处方 PDF**，并用系统默认 PDF 阅读器打开，可在阅读器里按 `Ctrl+P` 选择打印机。点“导出 PDF”会弹出保存位置。

## 8. 备份与恢复

- 每次保存立即写入 `data/clinic.db`；关闭软件、重启电脑都不会丢。
- 每天自动备份到 `data/backups/`，最多保留 7 份。
- 恢复：关闭软件，把某份 `clinic-YYYY-MM-DD.db` 复制为 `data/clinic.db`，再启动。
- 建议定期把整个 `data/` 复制到 U 盘或另一块硬盘。

## 9. 注意

- 本版本 Windows 可能会提示“未知发布者”（未做代码签名）；如确认来源可信，可选择继续运行。
- 不要同时开两个软件实例；软件已做单实例限制。
