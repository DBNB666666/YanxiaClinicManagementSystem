# 已知问题与限制（v0.6.1）

## 环境/验收限制

1. **低完整性目录会把 Electron 直接“静默杀死”**
   - 本机 `E:\Users\HP\Desktop` 被沙箱/AI 工具设置了 **Low Mandatory Level（低完整性）**；解压到该目录后双击 exe 没有窗口、没有进程。
   - 这不是业务代码崩溃，而是 Chromium/Electron 在创建窗口前被 Windows 限制；已通过 `npm run test:package` 在低完整性目录验证。
   - 解决：解压到 `C:\Users\HP\Desktop` / `C:\Apps` 等普通目录，或双击包内 `启动燕霞诊所管理系统.cmd`（复制到 `%LOCALAPPDATA%` 后启动）。
   - 详细排查与验证命令见 [TROUBLESHOOTING.md](TROUBLESHOOTING.md)。
   - 其他 Windows 电脑/系统打印/125%/150% 缩放仍建议按 [ACCEPTANCE_REPORT.md](ACCEPTANCE_REPORT.md) 手工复验。

2. **打印按钮走 PDF 阅读器**
   - “打印”生成正32开（130×190mm）图片模板 PDF 后调用系统默认 PDF 阅读器打开，由用户在阅读器里按 `Ctrl+P` 打印；没有直接弹 Electron 打印对话框。若需要一键系统打印对话框，后续可加。

3. **未做代码签名**
   - zip 未签名，Windows SmartScreen 可能提示“未知发布者”。

4. **图标**
   - 当前使用 Electron 默认图标，未做诊所品牌图标。

## 功能限制

- 没有登录、云同步、手机版、多设备共享。
- 没有患者档案/病历/预约；患者信息只跟着处方。
- 没有药品批次、效期、条码、供应商独立管理。
- 进货记录只追加，不提供编辑/删除。
- 财务只支持日/周/月/年，不支持自定义日期区间。
- 通知只在软件内，不做系统托盘/手机推送。
- 数据文件未加密；备份文件含患者信息，请妥善保管。
- sql.js 采用“内存库 + 整库原子写文件”；1000 张处方规模已测试，数据量特别大时保存会变慢，后续可换 better-sqlite3（Repository 接口不变）。

## 已知小问题

- 处方编辑页的库存提示用的是进入页面时的库存快照；如果同时在别处进货，需要重新进入页面刷新。
- 药房卡片上的“停用”入口会先进入详情页，再由详情页停用，不是卡片上直接停用。
- 深色/阅读模式下打印预览的纸张始终为白色（符合预期）。
